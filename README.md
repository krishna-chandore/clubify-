# Clubify 🎓

A college club management and collaboration platform built using Django.

## 🚀 Features

- Club registration and management
- Club details and event listings
- Admin dashboard for club management
- Gallery and resource sharing
- User authentication
- Club administration and collaboration

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript
- **Database:** PostgreSQL
- **Deployment:** Vercel

## 🌐 Live Demo

https://clubify-three.vercel.app

## ⚙️ Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL

Navigate to the project:

cd Clubify_fixed_v5

Create a virtual environment:

python -m venv .venv

Activate it:

.venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt
Configure environment variables in .env.

Run migrations:

python manage.py migrate

Start the server:

python manage.py runserver
